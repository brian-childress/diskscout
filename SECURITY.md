# Security and data-safety policy

diskscout runs locally, makes no network calls and sends no telemetry.

If you find a case where diskscout **recommends or applies** a change that loses data (or could), treat it as a security issue:

- Please report it privately through [GitHub Security Advisories](https://github.com/brian-childress/diskscout/security/advisories/new) rather than a public issue.
- Include the finding's category, the `reason` from `report.json`, and a description of the folder layout. Leave out personal paths.

Data-loss bugs are fixed before any other work.
